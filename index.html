De la descărcare la primul start

Pagina descarcă launcherul. Clientul NEXUS se instalează separat, din launcher, după ce alegi versiunea.

CERINȚE

Ai nevoie de un desktop Linux, Python 3, GTK 3 și PyGObject. Clientul NEXUS folosește și psutil. Este necesară o conexiune la internet pentru catalog și descărcarea versiunii alese.

UBUNTU / DEBIAN · DACĂ LIPSESC DEPENDENȚELE sudo apt install python3 python3-gi gir1.2-gtk-3.0 python3-psutil Pe alte distribuții Linux, instalează aceleași componente din managerul de pachete al sistemului.
  1. 01

    Descarcă launcherul

    Apasă butonul de descărcare de mai sus. Vei primi o arhivă .tar.gz pentru Linux.

  2. 02

    Instalează launcherul

    În Files, deschide Downloads și extrage arhiva. Clic dreapta pe folderul extras „NEXUS-Launcher-…”, apoi alege „Open in Terminal”.

    Dacă opțiunea lipsește: deschide Terminal, scrie cd urmat de un spațiu, trage folderul extras în fereastră și apasă Enter.

    ./install-launcher.sh

    Se instalează doar pentru utilizatorul curent și apare în meniul de aplicații. Nu cere sudo.

  3. 03

    Alege și instalează NEXUS

    Deschide NEXUS Launcher, selectează versiunea dorită și apasă Install. Launcherul descarcă clientul și îi verifică integritatea.

  4. 04

    Pornește aplicația

    După ce versiunea apare ca instalată, apasă Launch NEXUS. La pornirile următoare o poți deschide din launcher.

Launcherul distribuie clientul Linux NEXUS; nu este o versiune pentru Windows, macOS sau telefon. Dependențele sistemului nu sunt instalate automat.
